## 📌 Sobre o Projeto

Este repositório contém a landing page institucional e de captação do projeto de extensão universitária **Consultoria de Presença Digital** (`PEX-MDL-54`), conduzido por discentes do curso de **Bacharelado em Ciência da Computação** da **Uninassau Paulista**.

O propósito principal é atender comerciantes locais, feirantes e microempreendedores individuais (MEIs) com ponto comercial ou atuação no **Centro de Paulista - PE**, oferecendo consultoria presencial "mão na massa" para estruturação de perfis no Instagram e WhatsApp Business diretamente pelo smartphone do empreendedor.

## 🚀 Como Executar Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) (versão LTS recomendada: 20+)
- Gerenciador de pacotes `npm`

### Passo a passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Junior010101/projeto-extensao.git
   cd projeto-extensao
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
   Acesse a aplicação no navegador em `http://localhost:5173`.

4. **Executar o linter:**
   ```bash
   npm run lint
   ```

5. **Gerar a build de produção:**
   ```bash
   npm run build
   ```
